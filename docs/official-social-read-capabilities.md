# 官方社交读取通道

微博能力探针依据官方 `@weibo-ai/weibo-cli` 0.9.8（MIT）发布源码核对，使用固定 HTTPS 读取接口，未安装或启动官方 CLI，不读取日常账号的 keychain。调用前由本版本受控凭据引用解析授权，复用活动累计请求预算。仅允许检查服务状态、可用命令、已审查读取命令的元数据；发布、评论、关注和其他写操作不接入。

官方渠道默认关闭。开发者认证、服务已开通、搜索权限、正文读取、可信剩余额度和独立计费是不同条件。账号资料、令牌、认证地址不进入工作区、诊断或返回结果。当前没有受控 OAuth 凭据，没有已验证正文与剩余额度，保持“未配置”，自动业务调用为零。界面开关和伪造的 proofId 均不能越过服务检查；备份恢复清除证明并关闭服务。

微信仅认可自身或运营方实际授权且权限核验成功的公众号，不由发布权限推断任意账号可读。当前官方文档与账号权限尚未核验，授权读取保持不可用。公众号公开文章、微博公开正文与专用登录窗口继续独立工作。

官方服务费用不使用模型的 10 元预算代为购买。开通付费服务须独立明确确认；额度或计费未知时不执行自动业务调用。

核验依据：[微博官方 CLI](https://open.weibo.com/cli/quickstart)、[官方发布包](https://www.npmjs.com/package/@weibo-ai/weibo-cli)。未把文档说明或测试数据当作现场账号能力。
