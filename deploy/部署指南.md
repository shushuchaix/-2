# 公网部署指南

把「简历岗位雷达」发布到互联网，让任何人通过网址访问。

> **先读这段**：这个应用会带着**你的 DeepSeek API Key** 和**你的服务器 IP** 去访问招聘网站。
> 一旦公开暴露又没有防护，任何人都能消耗你的额度、并用你的 IP 去抓取别人网站。
> 因此本项目默认是 **fail-closed** 的：监听公网地址但没有配置登录口令时，**服务会直接拒绝启动**。

## 选择部署方式

| 方式 | 适合 | 难度 | 备注 |
| --- | --- | --- | --- |
| 云服务器 + Docker | 想要稳定长期运行 | ★★☆ | 推荐。国内选阿里云/腾讯云轻量，访问招聘站最快 |
| 云服务器 + 裸 Node | 不方便装 Docker | ★★☆ | 用 systemd 托管，同样稳定 |
| PaaS 平台 | 想几分钟跑起来 | ★☆☆ | 免运维，但**服务器多在境外，访问智联/实习僧会明显变慢** |

> **重要**：目标数据源（智联招聘、实习僧）都在国内。
> 用境外服务器会让抓取延迟从几十毫秒升到几百毫秒甚至超时，
> 检索一次可能要 2–3 分钟。**优先选国内服务器**。

## 方式一：云服务器 + Docker（推荐）

### 1. 准备服务器

- 一台 1 核 2G 的云服务器即可（阿里云/腾讯云轻量应用服务器，约 ¥60–100/年）
- 系统：Ubuntu 22.04 / Debian 12
- **安全组放行 80 和 443 端口**（不要放行 3210）

安装 Docker：

```bash
curl -fsSL https://get.docker.com | sh
sudo systemctl enable --now docker
```

### 2. 上传代码

```bash
# 在你本地打包（排除 node_modules 和 data）
tar --exclude=node_modules --exclude=data --exclude=.npm-cache -czf radar.tar.gz .

# 上传到服务器
scp radar.tar.gz root@你的服务器IP:/opt/
```

```bash
# 服务器上解压
mkdir -p /opt/radar && tar -xzf /opt/radar.tar.gz -C /opt/radar
cd /opt/radar
```

### 3. 配置环境变量

```bash
cp .env.example .env
nano .env
```

**必须填这两项**：

```ini
# 站点访问密码，请换成你自己的强密码（16 位以上）
AUTH_PASSWORD=你的强密码

# DeepSeek 密钥
DEEPSEEK_API_KEY=sk-你的密钥
```

**强烈建议再配一个搜索通道**（把检索范围从智联+实习僧扩展到全网）：

```ini
TAVILY_API_KEY=tvly-你的密钥
```

### 4. 启动

```bash
docker compose up -d --build
docker compose logs -f        # 看启动日志
```

看到这样就是成功了：

```
  访问地址：http://localhost:3210
  暴露范围：0.0.0.0（公网/局域网可达）
  鉴权状态：已启用密码登录
  配额限制：并发 2，每日全站 100 次 / 每 IP 10 次
```

### 5. 配置反向代理与 HTTPS

应用本身是**明文 HTTP**，直接暴露会让密码和简历内容以明文传输。
必须放在 nginx / Caddy 之后。见 [配置 HTTPS](#配置-https)。

## 方式二：云服务器 + 裸 Node（不用 Docker）

### 1. 安装 Node 20+

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
node -v    # 应显示 v22.x 或更高
```

### 2. 部署代码

```bash
mkdir -p /opt/radar && cd /opt/radar
# 上传代码后：
npm install --omit=dev
```

### 3. 配置环境变量

```bash
cp .env.example .env
nano .env     # 填入 AUTH_PASSWORD 和 DEEPSEEK_API_KEY
```

### 4. 用 systemd 托管

```bash
sudo nano /etc/systemd/system/radar.service
```

写入：

```ini
[Unit]
Description=Resume Job Radar
After=network.target

[Service]
Type=simple
User=www-data
WorkingDirectory=/opt/radar
EnvironmentFile=/opt/radar/.env
ExecStart=/usr/bin/node /opt/radar/src/server.mjs
Restart=always
RestartSec=5

# 安全加固
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/opt/radar/data

[Install]
WantedBy=multi-user.target
```

```bash
sudo mkdir -p /opt/radar/data
sudo chown -R www-data:www-data /opt/radar
sudo systemctl daemon-reload
sudo systemctl enable --now radar
sudo systemctl status radar
```

### 5. 更新代码

```bash
sudo systemctl stop radar
# 上传新代码覆盖
sudo chown -R www-data:www-data /opt/radar
sudo systemctl start radar
```

## 方式三：PaaS 平台（Railway / Render / Zeabur）

这类平台可以直接读 `Dockerfile`，最省事。

1. 把代码推到一个 Git 仓库（`.gitignore` 已配好，不会泄露 `config.json` 和 `.env`）
2. 在平台新建项目 → 选择该仓库 → 平台会自动识别 `Dockerfile`
3. 在平台的**环境变量**设置里填：

   | 变量 | 值 |
   | --- | --- |
   | `AUTH_PASSWORD` | 你的强密码 |
   | `DEEPSEEK_API_KEY` | `sk-...` |
   | `HOST` | `0.0.0.0` |
   | `TRUST_PROXY` | `1` |
   | `PUBLIC_URL` | 平台分配的域名 |

4. 平台会自动分配域名并配好 HTTPS

> **注意**：PaaS 多数在境外，抓取国内招聘站会很慢（可能 2–3 分钟一次），
> 且免费套餐会休眠。如果要长期用，还是建议国内服务器。

## 配置 HTTPS

### 方案 A：Caddy（最简单，自动申请证书）

```bash
sudo apt install -y caddy
sudo nano /etc/caddy/Caddyfile
```

把 `deploy/Caddyfile` 的内容粘进去，改掉域名，然后：

```bash
sudo systemctl reload caddy
```

Caddy 会自动申请并续期 Let's Encrypt 证书，无需其他配置。

### 方案 B：nginx

```bash
sudo apt install -y nginx certbot python3-certbot-nginx

# 1. 先放反代配置
sudo nano /etc/nginx/sites-available/radar
#    （内容取 deploy/nginx.conf，注意把 snippet 也放好）
sudo ln -s /etc/nginx/sites-available/radar /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# 2. 再签证书
sudo certbot --nginx -d jobs.example.com
```

> **踩坑提醒**：`deploy/nginx.conf` 里对 `/api/analyze` 显式设置了 `proxy_buffering off`。
> 这是必须的——检索要跑 40–90 秒且进度是逐行推送的，
> 如果开着缓冲，前端会一直卡在「正在启动…」直到全部结束才一次性显示。

### 域名与 DNS

- 在域名服务商添加 A 记录，指向服务器公网 IP
- 国内服务器需要域名**已备案**才能用 80/443

## 安全清单

部署完成后，请逐项确认：

- [ ] **已设置 `AUTH_PASSWORD`**，且不是弱密码
- [ ] 通过 **HTTPS** 访问（浏览器地址栏有锁标志）
- [ ] 服务器防火墙**只放行 80/443**，3210 端口没有对公网开放
- [ ] 在反代之后时 **`TRUST_PROXY=1`** 已设置
      （否则所有访客会被当成同一个 IP，限流形同虚设）
- [ ] **没有**在公网直连时把 `TRUST_PROXY` 打开
      （否则任何人伪造 `X-Forwarded-For` 就能绕过 IP 限流）
- [ ] `AUTH_MODE=none` **没有**被误开
- [ ] `config.json` 和 `.env` 没有提交到 Git 仓库
- [ ] 每日配额（`DAILY_LIMIT` / `IP_DAILY_LIMIT`）设置合理

### 关于「让任何人直接用，不要登录」

如果你确实想做完全开放的公开工具，需要**同时**设置：

```ini
AUTH_MODE=none
ALLOW_PUBLIC_NO_AUTH=1
```

这两个变量必须同时存在，是为了防止误配置导致服务在毫无防护的情况下暴露。

开放前请想清楚：

- 任何人都能用你的 DeepSeek Key 跑检索，**费用由你承担**
- 抓取请求会从你的服务器 IP 发出，**被封的是你的 IP**
- 建议把 `IP_DAILY_LIMIT` 调小（如 3）、`DAILY_LIMIT` 设为你能承受的上限

**更好的做法**：保持登录，同时开启「用户自带 Key」（默认已开启）。
访客在检索页展开「使用我自己的 DeepSeek API Key」填入自己的密钥，
费用由使用者承担，你只提供算力和抓取通道。

## 成本控制

一次检索的实际开销：

| 项目 | 用量 | 说明 |
| --- | --- | --- |
| DeepSeek Token | 约 2.5 万（输入 1.6 万 + 输出 1 万） | 画像提取 + 60 个岗位精排 |
| 招聘站请求 | 约 40–60 次 | 智联/实习僧列表页 + 12 个详情页 |
| 耗时 | 40–90 秒 | 取决于网络 |

按 DeepSeek 当前价格，**一次检索约 ¥0.05–0.15**。

限额配置建议：

```ini
# 个人/小团队自用
DAILY_LIMIT=50
IP_DAILY_LIMIT=10
MAX_CONCURRENT=2

# 公开给同学用
DAILY_LIMIT=200
IP_DAILY_LIMIT=5
MAX_CONCURRENT=3
MAX_QUEUE=10
```

配额计数持久化在 `data/quota.json`，**重启服务不会重置**，按自然日自动归零。

## 运维与排错

### 查看日志

```bash
docker compose logs -f          # Docker 方式
sudo journalctl -u radar -f     # systemd 方式
```

### 常见问题

**启动就退出，提示「拒绝启动」**

这是 fail-closed 保护生效了。日志里会直接告诉你怎么修：

```
拒绝启动：监听地址为 0.0.0.0（公网/局域网可达），但没有配置登录口令。
  请任选一种方式配置后重启：
    1) 环境变量：AUTH_PASSWORD=你的密码
    2) 生成哈希写入 config.json 的 auth.passwordHash
```

**前端一直卡在「正在启动…」，最后一次性刷出来**

反代的响应缓冲没关。检查 nginx 的 `proxy_buffering off;`（针对 `/api/analyze`）
或 Caddy 的 `flush_interval -1`。

**所有访客被识别成同一个 IP，限流失效**

`TRUST_PROXY=1` 没设置。设置后重启。

**检索很慢（2 分钟以上）**

服务器在境外。换国内服务器，或把 `maxPages` 调小：

```json
"sources": { "zhaopin": { "maxPages": 1 }, "shixiseng": { "maxPages": 1 } }
```

**提示「全站今日检索额度已用完」**

改 `DAILY_LIMIT`，或删除 `data/quota.json` 立刻重置（不建议用于公开站点）。

**忘了密码**

```bash
# 直接改 .env 里的 AUTH_PASSWORD，然后重启
docker compose restart        # 或 sudo systemctl restart radar
```

也可以用哈希方式（把密码写进 `config.json` 而不是环境变量）：

```bash
npm run hash-password -- "你的新密码"
```

### 数据与备份

需要备份的只有 `data/` 目录：

- `data/runs/` — 历史检索结果
- `data/font-map.json` — 实习僧字体映射缓存（丢了会重新学习，不影响正确性）
- `data/.session-secret` — 会话密钥（丢了所有人需重新登录）
- `data/quota.json` — 当日配额计数

```bash
tar -czf radar-data-$(date +%F).tar.gz data/
```

### 更新版本

```bash
cd /opt/radar
git pull            # 或重新上传代码
docker compose up -d --build
```

`data/` 已挂载为卷，更新不会丢失历史记录。
