# 命名版本、全版本岗位去重与数据位置交付报告

日期：2026-10-08。范围对应已批准的 [设计](../superpowers/specs/2026-10-08-workspace-version-and-dedup-design.md) 与 [11 项实施计划](../superpowers/plans/2026-10-08-workspace-version-and-dedup.md)。

## 产品变化

- 唯一目标版本名称、重复提交幂等，管理操作保持原编号。历史版本完整显示，失败保留输入，成功通过固定位置与 aria-live 通知。
- 精确目标版本成员与不可变观察事实；评价缓存必须匹配事实、画像与目标版本。历史分数不会覆盖无法验证的当前事实。
- 保守身份判定、两两确认的重复组、独立人工记录保护。全版本预览与确认事务覆盖停用、历史、回收站和未归属岗位。
- 清理前完整业务备份，原子归并，跨进程租约防止采集／评分／快照／恢复竞争；旧编号兼容详情、投递、评分、历史与旧版接口。
- 独立岗位筛选，实际数据位置卡片，主窗口／主框架保护的固定类别 IPC。只迁移两项有效已知缓存；凭据不随业务备份导出。

## 数据安全与使用限制

本轮开发、验证均使用合成隔离数据；未读取或清理日常 APPDATA、用户简历，不触发付费模型或真实招聘请求。新版日常启动会自动备份旧账本并补齐元数据；实际重复清理须由用户在软件内预览和确认。

同一岗位被多个目标版本引用属于正常关系。多个独立人工记录受保护；无法证明相同招聘机会的项目保留为疑似。完整备份恢复是整体回退，不能单组撤销，以免覆盖后续人工操作而误导用户。

权威账本、配置和加密凭据保持原文件位置；当前历史入口指向 `runs-v2`。目录路径仅向受保护的本地桌面界面提供，诊断仅保留白名单元数据。浏览器下载提示只确认已生成并触发下载。

## 实施判断与代价

| 判断 | 原因和代价 |
| --- | --- |
| API 测试等待应用启动完成 | 新备份 IO 暴露启动／清理竞态；测试启动略慢。 |
| 30 字正文要求用于纯内容证明，可信编号／具体链接可证明短记录 | 设计允许替代证据；生产者错误分类仍有误合并风险，故逐项声明来源。 |
| 失败的受保护操作也推进事务版本 | 跨进程租约需要落盘；旧清理预览可能需重新生成。 |
| 清理接口统一公开预览过期错误码 | 计划存在两种命名；内部门控和公开清理接口使用不同代码。 |
| 旧人工记录使用共享查询／投影函数 | 四类入口须一致；共享错误可能影响全部入口，已实测覆盖。 |
| 引用计数与错误编号扩展到 API／表单 | 管理失败须可解释；列表读取增加计数工作。 |
| 分类筛选扩展到校验、HTTP、服务和导入归属 | UI 条件必须实际生效；扩大了兼容检查范围。 |
| 确定但未清理的实体在列表归入疑似，人工保护优先 | 三类筛选没有额外待清理类；强证据需看清理预览。 |
| 缓存迁移保持同步并使用独占首次发布 | 保持启动调用约定和新缓存优先；短暂阻塞，不支持硬链接时保留旧缓存。 |
| 其余写操作与旧高校工具一起接入通知／目录 | 满足统一反馈；增加最终回归范围。 |
| 旧迁移复用完全相同生产者载荷 | 避免短记录重放新增实体；生产者范围错误仍可能误复用。 |
| 只按父目标查询时使用该岗位所属的最新版本事实 | 保留聚合成员且防止借分；聚合历史显示最新适用版本。 |
| 旧测试补齐版本观察及真实存储／UI 合约 | 新规则拒绝不可验证评分；弱化夹具会隐藏问题，原预算与业务状态断言保留。 |
| 合成服务先关闭、日志排空后删除目录 | 避免占用／重建导致测试卡住；改变了夹具失败清理行为。 |
| 最后任务的审查／推送作为整分支收尾门禁 | 当前会话流程要求对完成的提交统一审查；本地完成记录不等于已发布。 |
| 缓存只复用重定向等价实体 | 保持准确岗位与观察关联；独立同正文岗位可能增加模型请求，仍受共享费用上限约束。 |
| 精确版本工作台排除无法归属的旧运行 | 防止连接／取消其他版本任务；旧运行通过原历史入口访问。 |
| 备份恢复成功时重置旧界面状态 | 旧覆盖不能污染恢复结果；当前目标／岗位／任务选择被清除，失败则保留。 |
