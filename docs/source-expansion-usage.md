# 招聘扩源与证据核验使用说明

## 一、开始一次采集

1. 保存简历和求职目标，在顶部选中具体目标版本。
2. 打开「招聘来源」，启用国家大学生就业服务平台、机场官网、企业消防工程及需要的其他来源。候选来源须先通过探针；目录中的配置存在不代表当前网站可采集。
3. 在「工作台」选择规则或模型模式，点击更新来源。规则模式不调用模型。模型沿用设置中的 DeepSeek v4.1（`deepseek-flash`）及经过校验的价格，同一活动累计费用最多 **10 元**，0 元关闭模型。
4. 查看活动进度。新增记录、正文完整、待核验、失败来源分别显示。采集线索数不能代替有效岗位数。

标准活动最多24站、400请求、每查询4页、100详情；广覆盖最多50站、1000请求、每查询10页、300详情。一次分批最多10站。实际数量还受来源是否启用、探针、分页协议、站点限流及累计额度限制。

## 二、暂停、继续及额度

- 「暂停采集」保存游标和累计用量。「继续采集」沿用原活动，不会重置已花费用和未确定消耗。
- 暂停后可「保存活动额度」。新额度不能低于已经占用的资源；网络请求最高2000、每查询20页、详情600，模型仍最多10元。
- 暂停期间修改来源或检索条件后，点击「确认重新规划并继续」。页面说明会保留原活动累计用量；确认后才按新条件重新规划。达到单查询页数上限的来源不会挡住后续来源，提高页数额度后可继续原游标。
- 重试、跳转、DNS、浏览器静态资源、附件、304均计入自动请求。界面将已确认物理请求与未知请求预约上界分开；上界不能当作成功请求数。
- 「取消」终止这个活动。关闭桌面软件会保存中断状态；再次打开需手动继续。周期刷新默认关闭，启用后仍使用原活动预算。
- 429会遵守网站的等待时间；持续403、登录或验证码阻塞会保留受限状态。不要通过反复新建活动消除已发生的费用。

## 三、公众号和微博

在具体目标版本的来源设置中填入公开文章链接、账号标识或已核对的官网引用。优先使用机构官网确认的官方账号。昵称、搜索摘要和账号所在城市不能证明主体身份、工作城市或招聘条件。

公开读取可提取文章、微博正文、长文、公开海报及附件；正文截断、登录页或验证页不会算作完整正文。微博账号分页保存本版本游标，公众号使用公开链接和已配置的机构引用入口。没有通用的“任意公众号全历史”接口。

遇到登录限制时，在「招聘来源」点击「独立登录」→「打开独立采集窗口」，自行完成登录或验证码。窗口只属于当前目标，不读取日常浏览器的登录信息。随后在活动运行时使用正文验证，并检查返回状态。仅关掉窗口不会完成验证。

「清除登录材料」清除当前目标的专用会话。其他目标的会话保持独立。桌面版包含专用窗口；Web/CLI在缺少桌面能力时会显示不可用，不声称已登录。

可选官方社交服务默认关闭。核实账号读取权限、完整正文能力、额度及独立价格后才能开通；本次未购买服务或验证真实OAuth。人工登录流量单列，不作为自动采集成功证据。

## 四、岗位证据与推荐

在「岗位库」打开详情，检查正文、招聘时效、投递入口和资格条件；可按时效筛选。在活动运行期间可点击「核验正文与投递入口」，核验消耗同一活动额度。

| 状态             | 处理方式                                     |
| ---------------- | -------------------------------------------- |
| 资格符合         | 仍需核对正文、时效和投递证据                 |
| 资格未知         | 缺专业、证书、经验或其他明确条件，保留待核验 |
| 资格不符         | 不进入已核实推荐，模型高分不能覆盖           |
| 历史公示、已截止 | 保留历史证据，不能作为当前在招               |
| 投递入口待核验   | 表示尚未证明可用，不等于不能投递             |
| 登录或验证页     | 提示完成验证，不把HTTP200当作岗位正文        |

附件字段保留PDF页码、工作表/单元格、段落/表格或图像位置。文字PDF、DOCX、XLS/XLSX及扫描附件/公开海报采用本地解析或OCR；低可信OCR及无法确定行归属的条件保持未知。旧DOC缺少转换器时显示待解析。简历导入的扫描PDF暂不启用这一招聘附件OCR流程。

同一岗位的多来源证据可补全字段；存在专业、证书、城市、招聘批次等冲突时保留人工核对。文本相似只用来筛选候选，不能单独触发合并。全版本去重仍逐版本处理。

## 五、隔离、回收和诊断

每个目标独立保存简历副本、岗位、评价、投递、采集活动、游标、缓存和专用会话。整包移入回收站后隐藏子数据，满72小时永久清理；应用关闭时不运行清理，下次启动补清。恢复旧备份不会复活已永久删除内容或恢复有效登录材料。

更新失败时打开「日志」，按任务/活动、来源、阶段或错误编号筛选并导出。日志保留阶段计数、失败代码、HTTP状态、已知请求及预约上界；不导出简历、求职词、原URL参数、正文、凭据和私人路径。共享诊断时优先用这个导出入口。

## 六、便携版与本次线上限制

整个 `dist/简历岗位雷达-win32-x64` 目录一起移动，双击其中EXE。约1.29GB，包含固定Python、Scrapling、Chromium、OCR语言/WASM与原生模块；运行时不自动安装或下载这些资源。资源校验失败时显示对应不可用状态，不偷偷使用开发机运行环境。

2026-10-09的公开试点得到50条线索、13条正文通过，但有效推荐为0。公众号只有官网引用链接，正文仍受限；微博匿名入口没有验证成功。专用登录后的线上采集需用户自行登录再核验。详见[验收报告](reports/2026-10-09-source-expansion-validation.md)。
